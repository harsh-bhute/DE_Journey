# Sales Analysis Pipeline

## What it does
Analyses retail sales data answering 5 business questions.

## Business Questions Answered
1. Top performing product lines by revenue
2. Monthly revenue trend across years
3. Customer segmentation by total spend
4. Best performing month per year
5. Deal size breakdown

## Tech Stack
- Python 3.12
- PostgreSQL 18
- Pandas
- SQLAlchemy
- psycopg2

## How to Run
1. Add your credentials to .env file
2. Place sales_data_sample.csv in data/ folder
3. Run: python sales_analysis.py
