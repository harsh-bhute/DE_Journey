FROM  is the base layer for the image building ,meaning it will be based on Python 

WORKDIR defines working directory that is /app, it is created if not present 

COPY , it copies the requirements.txt file from local to the /app
THEN RUN this to install all the dependecies in requirements.txt file

after this we copy the etl_pipeline.py file to /app 
Also copy the .env to get the environment variables as well 

THEN using CMD we run the container that is python etl_pipeline.py 

Day 2:
- Services describe how docker compose should run a particular component of the application
- depends_on tells that the ETL service depends on db meaning we need to run the db service first in order to get ETL running
The volume here defines persistant storage of database files meaning even if we change or delete container the files will be stored safely
The Ports are mapped to 5433 because its a local host port and 5432 is port of db in container and they are mapped to each other so that the Postgresql can interact with local.
